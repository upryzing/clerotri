# Notice on AI-generated contributions

AI-generated contributions are **not welcome** in this repository.

- Pull requests with AI-generated code will be closed.
- Regarding AI-generated commit messages and PR descriptions, we may either ask you to reword them or (as above) close the PR.
- AI-generated issues will, at best, be deprioritised - if the issue is deemed to be invalid, it will be closed.
- AI-generated comments may be hidden as spam.
- AI-generated imagery will be deleted on sight.

If you're nervous about the quality of your writing, don't be - we _vastly_ prefer broken grammar and spelling to AI slop. You're also more likely to improve if you practice!

...and if you can't be bothered to write a lengthy issue, just write the basic details and we can ask for more info if needed.

If you _still_ want to use AI... well, why should we bother to read something you couldn't be bothered to write yourself - especially if you're not paying us? If we wanted to use AI tools, we would do so directly.

Repeat offenders will be blocked from interacting with the Upryzing GitHub organisation.

## Exceptions

The _**only**_ exception is machine translation. Machine-translated issues/comments and PR descriptions _are_ allowed, but we ask that you:

- disclose that the comment was machine-translated, and
- include the original, untranslated comment - this can be useful if something gets lost in translation.
